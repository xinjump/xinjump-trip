# 🗺️ xinjump-trip · 旅行攻略合集

纯前端实现的旅行攻略生成器：选择目的地与行程参数，一键生成包含交通、住宿、逐日行程、美食、景点、特产购物、预算与避坑指南的完整攻略页。

**零依赖、零构建**：原生 HTML + CSS + JavaScript，任何静态服务器或直接双击 `index.html` 即可运行。

## ✨ 功能特性

### 攻略生成

- **一键生成**：首页选择目的地 / 天数 / 人数 / 人均预算，自动跳转生成专属攻略
- **人均预算档位**：支持「经济实惠 2000-4000 元 / 舒适标准 3500-6500 元 / 品质尊享 5000-10000+ 元 / 智能推荐」四档，选定后**内容随之调整**：预算数字按档位区间计算、住宿按每晚上限筛选、每日行程中的餐饮替换为对应价位的当地推荐、美食清单按价位精选、景点清单按票价重排，整体不超出所选预算
- **吃喝不重样**：每日行程中的美食自动去重——同一美食每天最多出现 1 次、全程最多保留 2 次（视为热门推荐），补充日午餐/晚餐必选不同款式；去重不足时替换为其他当地美食，避免连吃多天同一家
- **行程自动补足**：所选天数超出城市模板收录范围时，自动基于该城市景点/美食库补足行程，并给出提示
- **交通动态估算**：往返大交通按出发地/目的地距离自动估算高铁/飞机耗时与票价区间
- **完整攻略区块**：目的地简介、交通方案、住宿推荐、每日行程、地道美食、景点参考、🛍️ 本地特产 & 购物地、预算估算、避坑贴士

### 交互与编辑

- **行程可编辑**：点击「✏️ 编辑行程」进入编辑态，可**直接修改文字**、增删行程项、上下移动排序，改动自动保存到 `localStorage`；再次进入时自动定位到上次修改的行程项
- **侧边操作面板**：页面右侧可收起/展开的浮动操作面板（⚙️），包含：编辑行程、还原默认、复制行程文本、复制 Markdown、打印 / 保存 PDF、切换夜间模式
- **一键还原默认**：还原默认模板并清除该行程的编辑记录
- **复制导出**：支持复制为**纯文本**与 **Markdown** 两种格式（带成功提示）
- **地图跳转**：景点表格含「地图」列，点击后选择**高德 / 百度**地图跳转查看位置；选择结果记忆 30 分钟，期间不再重复询问
- **历史与收藏**：首页「👣 我的足迹」分区展示**最近生成的行程**（点击可重新生成）与**收藏的城市**，历史与收藏可分别一键清空（自定义确认弹窗，非浏览器默认）
- **逐日行程**：每日卡片按时间轴展开，点击标题可折叠/展开当天内容
- **快捷导航**：吸顶导航条 + 平滑滚动；「每日行程」下拉菜单支持一键定位到任意一天（D1~Dn）
- **URL 直链**：支持 `custom.html?from=西安&to=青岛&days=5&persons=2&budget=comfort` 参数直达，便于分享
- **深色模式**：操作面板中的 🌙 按钮或 `Ctrl + D` 切换，偏好保存在 `localStorage`
- **打印友好**：打印时自动隐藏表单与导航，展开全部行程，适合导出 PDF
- **响应式布局**：适配桌面 / 平板 / 手机，默认出发地为西安

### 城市选择面板

- **搜索式目的地选择**：首页目的地输入框点击弹出底部面板，支持**搜索定位**（输入关键词实时高亮首个匹配，不过滤列表）、**最近选过**（独立于生成历史，可一键清空）、**热门城市**、其余城市按拼音 **A-Z 分组**并带**悬浮字母索引条**快速跳转；面板只能点击 ✕ 或选中城市关闭

### PWA 安装与离线

- **可安装到桌面**：配置 `manifest.json` 与 `assets/icon-512.png`，浏览器可将站点安装为桌面 / 主屏幕应用（独立窗口运行，入口在 Chrome/Edge「安装」按钮或 Safari「添加到主屏幕」）
- **离线可用**：`sw.js` 预缓存全部页面与 37 城数据，安装后无网络也能打开站点生成攻略
- 需部署到 **HTTPS**（如 GitHub Pages / Vercel / Netlify）才能触发安装与离线缓存；直接双击 `index.html`（`file://`）无法注册 Service Worker

## 🚀 快速开始

### 方式一：本地直接打开

双击 `index.html`，在浏览器中即可使用。

> 建议通过本地静态服务器访问（部分浏览器对 `file://` 下的动态脚本加载有限制）：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080/`。

### 方式二：直接指定参数生成

浏览器打开：

```
custom.html?from=西安&to=青岛&days=5&persons=2&budget=comfort
```

| 参数 | 说明 | 示例 |
| ---- | ---- | ---- |
| `from` | 出发地 | `西安` |
| `to` | 目的地 | `青岛` |
| `days` | 旅游天数（3-10） | `5` |
| `persons` | 出行人数（1-10） | `2` |
| `budget` | 人均预算档位（`economy` / `comfort` / `quality` / `auto`，可选，默认 `auto`） | `comfort` |

### 方式三：安装为桌面应用（PWA）

1. 部署到任意 HTTPS 静态托管（如 GitHub Pages）
2. 手机：浏览器打开后「添加到主屏幕」；电脑：Chrome/Edge 地址栏「安装」按钮
3. 点击桌面图标即全屏打开，可离线使用

## 🏙️ 城市数据结构

每个城市文件向 `window.CITY_DATA` 写入一条数据，结构如下：

```js
window.CITY_DATA['青岛'] = {
  cover:      'CSS 渐变封面背景',
  emoji:      '封面图标',
  tagline:    '一句话副标题',
  bestMonths: '最佳旅行月份，如 5-10月',
  intro:      '城市简介 1-2 句',
  transport:  [ { mode: '🚄 高铁（推荐）', line: '班次/路线', time: '耗时', price: '参考价' } ],
  hotels:     [ { type: '经济型', rec: '推荐区域/酒店', price: '参考价/晚', note: '特点' } ],
  foods:      [ { name: '美食名', shop: '推荐店铺', per: '人均', note: '备注', must: true } ],
  spots:      [ { name: '景点/项目', ticket: '参考费用', time: '建议时长', note: '亮点', must: true, lat: 39.9, lng: 116.4 } ],
  specialties: [ { name: '本地特产', shop: '购买地/店铺', price: '参考价', note: '备注' } ],
  shopping:   [ { name: '购物地', rec: '推荐区域/商场', note: '特点' } ],
  days: {  // 3-7 天行程模板，键为天数
    3:  [ { title: 'D1 主题', tag: '标签', items: [ { t: '上午', x: '安排' }, ... ] } ],
    4:  [ ... ],
    5:  [ ... ],
    6:  [ ... ],
    7:  [ ... ]
  },
  budget: {
    perDay:    [最低, 最高],   // 人均每日目的地消费（住+吃+市内交通+门票）
    transport: [最低, 最高],   // 往返大交通人均
    note:      '预算说明'
  },
  tips: [ '避坑/实用贴士（数组）' ]
};
```

> 字段说明（就近不绕路 + 必去优先）：
> - `spots[].must`：`true` 表示「必去」景点，天数少时也优先保留，不会因天数不足被砍掉
> - `spots[].lat` / `spots[].lng`：经纬度坐标，用于行程生成时做「就近贪心排序」保证路线不绕路，同时用于景点「地图」列跳转（可省略，省略时该点排到末尾并仅按 must 优先）
> - `foods[].must`：`true` 表示「必吃/必喝」，优先进入每日餐饮清单
> - `specialties` / `shopping`：本地特产与购物地，生成「🛍️ 本地特产 & 购物地」区块（建议各 3-5 条）

## ➕ 如何新增城市

两步即可：

1. **新建数据文件**：复制任一现有城市文件（如 `cn/tier1/beijing.js`），放到对应目录：
   - 国内城市 → `assets/js/cities/cn/<线级>/xxx.js`（`tier1` / `tierNew` / `tier2` / `tier3`）
   - 港澳台 → `assets/js/cities/hk-mo-tw/xxx.js`
   - 海外 → `assets/js/cities/overseas/<国家或大洲>/xxx.js`（目录不存在则新建）

   按城市数据结构写入数据（`days` 至少提供一个 3-7 天模板，`foods` / `spots` 建议 8 条以上，便于行程自动补足）。
2. **注册城市**：在 `assets/js/cities.js` 的 `CITY_LIST` 中，按地区分组插入一条记录（`region` 与 `tier` 决定目录归属与排序权重，无需手动排位置）：

```js
var CITY_LIST = [
  /* ---- 中国内地 · 一线 ---- */
  { name: '北京', region: 'cn', tier: 'tier1', file: 'cn/tier1/beijing.js' },
  // ...
  /* ---- 海外 ---- */
  { name: '东京', region: 'overseas', tier: 'overseas', file: 'overseas/japan/tokyo.js' }
];
```

字段说明：

| 字段 | 取值 | 说明 |
| ---- | ---- | ---- |
| `region` | `cn` / `hk-mo-tw` / `overseas` | 所属地区，决定目录归属 |
| `tier` | `tier1`(一线) / `tierNew`(新一线) / `tier2`(二线) / `tier3`(三线及以下) / `overseas`(海外) | 线级，决定下拉排序 |
| `file` | 相对 `assets/js/cities/` 的路径 | 与 `region`/`tier` 对应的实际文件位置 |

保存刷新后，新城市会自动出现在首页目的地选择面板与生成器的目的地选项中，并按线级自动排序（首页热门目的地为独立精选清单，如需上榜请同步 `index.html` 的 `HOT_NAMES`）。

## 🛠️ 技术要点

- **无框架**：原生 JS + 字符串拼接渲染，`custom.html` 中 `build()` 负责生成攻略 HTML
- **数据加载**：`cities.js` 定义 `CITY_LIST`（兼容浏览器与 Service Worker 环境），页面动态注入各城市 `<script>`，全部加载完成后初始化
- **行程生成流水线**：`getPlan`（取模板或补足）→ `extendPlan`（超天数补足，补充日午/晚餐各取不同款）→ `ensureLunch`（补上午餐）→ `applyBudgetToPlan`（按档位替换餐饮）→ `dedupePlan`（最终去重巡检：每天 ≤1 次、全程 ≤2 次）
- **美食识别防误判**：餐饮行识别会先剥离括号（店名/价格）与备注再匹配，多个同名子串取最长（如「海鲜」⊂「海鲜水饺」），店名命中只计数不替换，避免共享店名（如楼外楼）导致误替换
- **行程编辑**：编辑态基于 `contenteditable`，移动/删除通过按钮操作 DOM；每次改动序列化后按行程维度写入 `xj-trip-edit-v1-*`，重新生成时静默恢复内容；进入编辑态自动 `scrollIntoView` 定位到上次修改项
- **侧边操作面板**：`position: fixed` 浮动于页面右侧中点，⚙️/✕ 切换展开收起；编辑模式下面板常驻；点击外部自动收起；夜间模式按钮随构建实时读取 body 状态
- **城市选择面板**：底部弹出 modal；搜索时保留完整列表并高亮/定位首个匹配；字母索引条固定于面板右侧（`position: sticky` 类方案 + `getBoundingClientRect` 计算滚动位置）；「最近选过」独立存储于 `xj-trip-city-selected`，与生成历史 `xj-trip-history` 数据隔离
- **地图跳转**：`openMap` 按 `xj-trip-map-choice` 选择高德（`amap`）或百度（`bdmap`）打开外链；选择弹窗 `showMapPicker` 记忆选择并带 30 分钟过期时间戳
- **自定义弹窗**：`showConfirm(opts)` 返回 Promise，支持标题/正文/确认与取消文案及 danger 样式，替代浏览器原生 confirm（确认在左、取消在右）
- **每日定位**：快捷导航下拉通过锚点 `#day-N` 实现逐日定位，`scroll-margin-top` 抵消吸顶导航遮挡；下拉支持 hover 与 click 两种展开方式
- **行程折叠**：基于 `resultBox` 事件委托，点击 `.day-header` 切换当天折叠状态
- **打印适配**：`@media print` 下隐藏表单与导航、展开全部行程、保留封面配色
- **PWA**：`manifest.json` 声明应用信息（`display: standalone`、`start_url: .`）；`sw.js` 在 `install` 阶段通过 `importScripts(cities.js)` 动态获取全部城市文件列表并预缓存，`fetch` 走 cache-first 并回写新资源，`activate` 清理旧缓存；缓存版本 `xinjump-trip-v2`，升级时自动失效旧缓存
